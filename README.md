# Opinionated Guide to AI
By [Steven-Shine Chen](https://stevenshinechen.github.io), Twitter: [@stevenshinechen](https://x.com/stevenshinechen)

An opinionated collection of learning resources for AI. Covers the whole breadth from courses, to books, to podcasts and more. Includes everything you need, from learning how to code well to foundational mathematics behind AI.

These are the resources I've personally found useful and of high value. It is not a comprehensive list.
